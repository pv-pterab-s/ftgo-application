# Common Table pull request reviews

Common Table uses this FTGO fork for its application source. CodeIntent reviews
pull requests through the repository’s CodeIntent Checks workflow.

Open the review link on a pull request to inspect the assessment for its exact
source revision. A completed assessment may identify a required review or
incomplete evidence; it does not by itself authorize merging the change.

This documentation change exercises the GitHub-to-AWS review integration
without changing FTGO application behavior.
